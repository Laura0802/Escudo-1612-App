# Escudo 1612

App interactiva sobre el **Grupo de Trabajo de Niños y Conflicto Armado** del Consejo de
Seguridad de la ONU.


## Cómo verlo

- **Publicado:** abre el enlace del sitio.
- **En local:** abre `index.html` directamente


## Créditos

Diseño conceptual y desarrollo: Laura Aguiar Díaz.
Proyecto educativo e independiente. No es una publicación oficial de las Naciones Unidas ni de
UNICEF, y no sustituye a los informes originales de esos organismos.
